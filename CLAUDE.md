# AiKELA project instructions

Read `AGENTS.md` before answering questions or changing files. It contains the shared role, source hierarchy and SSA accuracy rules.

Pack-specific profiles, templates, planners and programmes live under `packs/<pack-slug>/`. For Pack-specific work, read `packs/<pack-slug>/PACK-PROFILE.md`; never assume one Pack's arrangements apply to another. The `packs/1st-pinelands/` folder is an example only. If a Pack profile is unavailable, ask for local details or state assumptions.

Preserve source documents. Do not invent SSA requirements. Keep official source material, Pack practice and AI suggestions distinguishable. Use the selected Pack's local meeting template when creating a programme.

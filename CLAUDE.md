# AiKELA project instructions

Read `AGENTS.md` before answering questions or changing files. It contains the shared role, source hierarchy, SSA accuracy rules and programme guidance for this repository.

For Pack-specific work, read the relevant profile at the repository root (for example, `1stPinelands.md`). Never assume that one Pack's arrangements apply to another Pack. If no profile is supplied, ask for local details or state assumptions.

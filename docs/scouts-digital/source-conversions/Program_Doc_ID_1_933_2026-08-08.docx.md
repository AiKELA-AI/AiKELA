Theme:  Healthy Eating

Date:  08 August 2026

Advancements:  Outdoor Challenge

Duty Six:  Brown

| Time | Activity | Person in charge | Equipment |
| --- | --- | --- | --- |
| 2:30 pm<br>10 min | Opening<br>Flag, Prayer, Cub promise<br>Inspection: Nails, handkerchiefs, badges and uniform | All Pack Scouters |  |
| 2:40 pm<br>10 min | Activity 1:  Greek Salad<br>Cubs to stand in a circle and must respond correctly to the instructions given. Actions to be performed in a circle<br>Lettuce: lie flat on the ground<br>Cucumbers: wiggle your body<br>Olives: Duck walk<br>Feta Cheese: Hop on one leg<br>Onions: Action on crying<br>Greek Salad: cubs to run to a cone that is outside the circle.<br>Remove a cone as the number of cubs reduce<br>Cubs can lose a life if they are the last to obey the command, if they do the wrong thing or fail to get to a cone | Prakashini |  |
| 2.50 pm<br>10 min | Activity 2:  Healthy Foods and Unhealthy Foods<br>Discuss vitamins, good and bad foods. | Nila |  |
| 3:00 pm<br>10 min | Activity 3: Word game<br>Cubs to choose an alphabet and they must write down a healthy food and a junk food starting with that alphabet | Prakashini |  |
| 3.10 pm<br>10 min | Activity 4: Fruit salad game<br>Cubs to sit in a circle on a chair. Each cub is given a name of a fruit ( apple, banana, grape, nartjie). A name of a fruit is called and they have to switch seats with another person of the same fruit<br>Call “fruit salad” and everyone needs to switch seats. You cannot sit in your own seat and you remove one chair as the rounds go. | Nila |  |
| 3:20 pm<br>40 minutes | Activity 5: Make a fruit salad<br>Cubs to wash their hands.<br>Wash the fruit<br>Make a fruit salad.<br>Enjoy the fruit salad<br>Wash up | Prakashini |  |
| 4.00 pm<br>10 min | Activity 6: Memory game - Listening<br>Read the Yarn “ cub messenger” and cubs to remember the items that had to be collected | Nila |  |
| 4:10 pm<br>10 min | Activity 7: Matching cards<br>Cubs to match the memory cards | Prakashini |  |
| 4:20 pm<br>5 min | Activity 8: Toothpicks<br>Each cub is given 10 toothpicks and each one has a turn to stack a toothpick on top of a bottle.  If the sticks drop that cub has to take all the sticks.  The winner is the cub that finishes their sticks first. | Nila |  |
| 4.25 pm<br>5 min | Closing<br>Flag, Prayer<br>Law and Promise, Notices and reminders<br>Badges | All pack scouters |  |
| 4:30 pm | Dismiss | APS |  |

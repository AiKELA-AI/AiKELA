# Advancement Tasks

This folder gives each task from the latest locally available SSA source its own page. The grouped knot requirements stay together on one page per badge. The source is [The Cub Trail, November 2019](../The-Cub-Trail-Nov-19.pdf); the Silver and Gold Wolf Challenge Badge Requirement PDFs dated August 2014 are historical. Use the Cub Trail where wording differs. Practice resources are suggestions; using one does not by itself complete a requirement. Check the full requirement before recording completion.

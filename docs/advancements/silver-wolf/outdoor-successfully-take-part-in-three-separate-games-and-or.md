# Successfully take part in three separate games and/or activities which involve using knots.

## Requirement

> Successfully take part in three separate games and/or activities which involve using knots.

**Badge:** Silver Wolf
**Source:** [Silver Wolf requirements, Outdoor section](../../Silver-Wolf-Challenge-Badge-Requirements.md#outdoor)

## Challenge

**Challenge:** Outdoor

## Related elements

These games use knots in their instructions. The task requires participation in three separate knot games or activities; a link does not prove that a Cub completed the requirement.

- [Knotting](../../games/knotting-game.md) — Uses a reef knot in a relay; this can count as one separate knot game.
- [Knotting Revision of the knots the](../../games/knotting-revision-of-the-knots-the.md) — Uses reef, slip reef and figure-of-eight knots in a relay; this can count as one separate knot game.
- [Knotting Market On ‘go’ the](../../games/knotting-market-on-go-the.md) — Cubs tie knots for a Scouter to check; this can count as one separate knot game.

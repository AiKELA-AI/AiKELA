# Play sense training games involving memory and feel and achieve a 70% score.

## Requirement

> Play sense training games involving memory and feel and achieve a 70% score.

**Badge:** Silver Wolf
**Source:** [Silver Wolf requirements, Awareness section](../../Silver-Wolf-Challenge-Badge-Requirements.md#awareness)

## Challenge

**Challenge:** Awareness

## Related elements

These games, activities and crafts offer relevant practice. Read each note to see what it covers; a link does not prove that a Cub completed the requirement.

- [Who Is Missing?](../../activities/Who-is-Missing.md) — Practises memory with the Pack; pair it with a tactile game and score the combined sense-training work against the 70% requirement.
- [Touch in Sand](../../games/touch-in-sand.md) — Cubs identify objects by feel. Pair it with a memory game and record the required 70% score; this game covers the tactile part only.

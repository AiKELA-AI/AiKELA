# Explain the buddy system.

## Requirement

> Explain the buddy system.

**Badge:** Silver Wolf
**Source:** [Silver Wolf requirements, Aptitude section](../../Silver-Wolf-Challenge-Badge-Requirements.md#aptitude)

## What to teach

**Scouter teaching notes (general guidance, not additional badge criteria):**

- A buddy is a partner who stays with you and checks that you are safe.
- Agree where to stay together and which trusted adult to go to if separated.
- A buddy system supports adult supervision; it does not replace it.

|  | 05 | ACTIVE GAME: Chain Tag Cubs are scattered over the playing area. One player is “IT” and tries to tag another player. The first Cub he/she tags joins hands with him/her and helps in tagging others. Both may use only their free hand to tag. Each player tagged joins hands with the one tagging him/her. The line grows longer as more players are tagged, but only the players at the two ends of the chain may do the tagging. Tagging doesn’t count if the chain is broken. The game continues until all the Cubs have been tagged. | None |  |

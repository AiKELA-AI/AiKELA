# Save Water

## Type

RELAY GAME

## Equipment

Two containers; sponges/cloths; water

## Instructions

RELAY GAME: Save Water In Sixes – each Six needs two containers. Place one at the starting line and one a few metres away. Fill the farthest container with water. Cubs take a sponge/cloth and run to the farthest container, dip the sponge/cloth into the water and then run back to the starting line container and squeeze the water into the empty container. After 5 minutes or so see whose container holds the most water. You can also let the game run until all the water has been transferred from the farthest container to the closest.

# Bear Attack

## Type

CIRCLE GAME

## Equipment

Six beanbags; six targets.

## Instructions

CIRCLE GAME: Bear Attack Cubs in a circle, numbered off from 1 to 6. Beanbags (spears) are in the centre of the circle. Targets (bears) are stuck to the wall, one for each Six. As a number is called the Cubs run round the circle, back through their space, grab a beanbag, run back through their place to a target and throw the beanbag from a given line. First one to hit the target gets a bean. If they miss, they pick up the beanbag and try again. Repeat using the other numbers.

**1st Pinelands reward adaptation:** use beans where this POP source uses bones as reward counters. References to actual bones remain unchanged.

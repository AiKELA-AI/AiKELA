# Bean Planting

## Type

## Equipment

1 egg box per Six; 1 bean per Cub

## Instructions

RELAY GAME: Bean Planting Place an egg box in front of each Six. In relay formation, the cubs are to run up carrying a bean and “plant” it in the egg box.

# Dodge mosquitoes

## Type

CIRCLE GAME

## Equipment

Stocking or newspaper balls or similar

## Instructions

CIRCLE GAME: Dodge mosquitoes Cubs stand in a circle - three Cubs are in the middle. Other Cubs throw stocking balls (newspaper balls) at them - if hit then they need to swap places.

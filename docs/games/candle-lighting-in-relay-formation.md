# Candle Lighting In relay formation

## Type

RELAY GAME

## Equipment

1 candle; 1 candle holder; matches

## Instructions

RELAY GAME: Candle Lighting In relay formation, Cubs to run up, light a candle properly, blow it out and run back to the Six. All Cubs in the Six to sit quietly once they have all had a turn.

# Captain on Deck

## Type

ACTIVE GAME

## Equipment

None

## Instructions

ACTIVE GAME: Captain on Deck A Leader is First Mate and calls out orders which the Pirates must obey immediately (or be eliminated for two turns). The playing area/room is the ship, with the positions Bow (front of playing area/room). Stern (rear of playing area/room), Port (left side), Starboard (right side); when any of these points are called, the Pirates must run to that part of the ship.

# Smell Trail

## Type

ACTIVE GAME

## Equipment

Small square of sponge; different scents

## Instructions

ACTIVE GAME: Smell Trail. Buy inexpensive sponges (all the same colour) and cut them into small squares. Soak equal numbers of squares in different scents (e.g. vanilla, mint or soy sauce). Lay a trail for each scent. Divide the Cubs into Sixes and have each Six follow a particular scent trail. Add trail signs if helpful. Rotate the Sixes so each follows all the trails.

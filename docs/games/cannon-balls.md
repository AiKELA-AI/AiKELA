# Cannon Balls

## Type

SIX GAME

## Equipment

1 bucket/box per Six; three tennis balls/paper balls per Six

## Instructions

SIX GAME: Cannon Balls The cannon balls have to be tossed up from the ship’s hold into buckets next to the cannons. Each Six has a bucket/box and three tennis balls/paper balls; each Cub has three attempts to toss the balls into the bucket/box. Total up the number of successes for each Six.

Active Game: Resource Dash: The Natural Element Challenge
How to Play:
Kids line up at the start line in two lines behind each other.
The leader calls out an item that depends on one of those natural resources:
"River / Fish / Rain" Move LEFT (Water)
"Vegetables / Crops / Worms" Move RIGHT (Soil/Land)
Paper / Apples / Wood" Move MIDDLE (Trees & Forests)
Man-made Items (e.g., Plastic, Metal) FREEZE / STAND STILL (or FREEZE / STAND STILL if an item needs no resource, like plastic or metal).
Any player who moves in the wrong direction or fails to freeze when required goes back 2 steps! First group with all players to reach the end wins.

## Type

## Equipment

## Instructions

ACTIVE GAME: Ship’s Messengers Spread the Cubs around a given course in their Sixes. A member from each Six should be at each post. A Scouter reads a short message and repeats it 2 or 3 times to the first player from each Six who may, as soon as possible, run to the next post and pass on the message and so on. See who comes back with the correct message. The Cubs must not shout the message out as they pass it on; they should whisper otherwise the Cubs from the other Sixes will hear.

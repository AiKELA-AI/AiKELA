# Jump Rope

## Type

TEAM GAME

## Equipment

One long or a couple of smaller ropes tied together

## Instructions

TEAM GAME: Jump Rope Two Leaders hold each end of the rope and turn it. The Cubs line up and allow two to jump together. Allow two jumps per Cub, as one person leaves another can join. This takes a lot of team work but is a lot of fun!

# Cardboard Ball Run

## Type

Cooperative moving-channel game; 10 minutes

## Equipment

A piece of cardboard per Cub and a ball.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

Cubs stand in a line holding their cardboard as a continuous route for a rolling ball. Once the ball passes a Cub’s piece, that Cub moves to the far end and rejoins the route. See how far around the hall the ball can travel before falling.

## Preparation and review

**Scouter guidance / extraction notes:** Clear the route, use walking and safe cardboard edges, and allow enough turning space.

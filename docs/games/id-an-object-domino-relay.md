# ID an Object Domino Relay

## Type

Game

## Instructions

Whole Pack—user-created ID an Object Domino Game. Working setup assumption: one complete, equivalent set per Six, marked on the back with the Six colour. Before the meeting, check that each set makes a complete chain and that the pictures clearly distinguish top and side views. Lay each set jumbled in its own assembly area at one end of the hall; Sixes line up at the other end in separate lanes. On the signal, the first Cub runs to their pile and places ONE domino to start the chain, then returns before the next Cub leaves. Each following Cub places ONE domino beside an exposed end, matching the top view of an object to the side view of the same object. Top and side views of an object are on different dominoes. Cubs may rotate a domino to make the match. If a Cub needs help, let them identify the matching object with a Scouter; other Cubs remain behind the start line. Finish when the complete chain is correctly matched; check it before declaring the winning Six. Award beans for the result and helpful teamwork. Keep paper outside the running lanes and leave clear stopping space before the assembly area. Offer a walking turn or an equivalent seated placing role. Scouters observe individual recognition; a team win alone is not advancement evidence. The supplied description is user-created; separate sets, starting rule, checking and safety details are AI planning additions.

## Advancement / badge link

Silver Wolf Outdoor: Identify a simple object viewed from the side and top to illustrate the difference in shape. Cub Trail November 2019, p.12. Assess the individual’s identification and explanation.

# Find the Footprint

## Type

Steam Release

## Equipment

Footprint templates; paper or card in a different colour for each Six; scissors; a clear playing area

## Instructions

Prepare one set of footprint puzzle pieces for each Six, using a different colour for each team. The attachment image can be copied or used as a pattern. Cut each set into pieces and scatter them around the playing area. Divide the Cubs into Sixes. Each Six searches for the pieces in its colour and puts the footprints together. The source does not state a time limit or winner.

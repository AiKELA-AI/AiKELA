```text
Active Activity: Memory Game
Overview & Setup
Bases: Set up 3 distinct memory bases (Game A, Game B, Game C).
Time: Each Six (group) spends 6 minutes at each base before rotating.
Station Breakdown
Game A: Ball Sequence
The Setup: Arrange 5 coloured balls in a specific sequence and cover them.
The View: The Six gets one opportunity to look closely at the correct sequence before it is hidden again.
The Game: The give each Six member 6 balls to attempting recreating the exact order of the 5 coloured.
Game B: Mystery Box (Touch, Smell & Taste)
The Setup: Place 6 hidden items inside a container/box. This includes items to touch, smell, and taste.
The Game: The Six forms a single line. Each member takes a turn reaching inside the container to identify the 6 mystery items.
Game C: Song Order
The Setup: Play a playlist of 5 short song clips.
The Game: The Six sits in a circle, listens to the songs, and works together to recall and guess the exact order in which the songs were played.
```

# Build a Tower

## Type

TEAM GAME

## Equipment

Toothpicks, match sticks, etc.

## Instructions

TEAM GAME: Build a tower Using toothpicks, match sticks or similar let the Cubs work together in Sixes to see who can build the highest structure. Let the Cubs build on a table. Once built they need to hit on the table next to the tower to see if the structure they built can withstand the earthquake!

# Bright Colours

## Type
Steam release

## Equipment
About 20 pieces of coloured paper, with a different colour assigned to each Six

## Instructions
Scatter the coloured paper outside over a wide area. Assign each Six a different colour. Cubs run outside and gather as many pieces as they can, but only the colour assigned to their Six. See which Six can collect all its pieces first.

## Advancement covered
None listed in the source.

## Tags
colours, Sixes, running

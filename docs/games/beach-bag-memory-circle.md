# A Day at the Beach — Bag Memory Circle

## Type

Cumulative memory game; 15 minutes

## Equipment

None.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

Sit in a circle. The leader begins “In my bag I have a sun hat”. Each next Cub repeats the list and adds one suitable item, e.g. water. Continue until the group cannot remember any further items. The source does not add a score or elimination system.

# Repeat the Message

## Type

REVISION GAME

## Equipment

Some prepared messages for the Cubs to remember – should be a short sentence

## Instructions

REVISION GAME: Repeat the Message Cubs sit in a circle around the edge of the hall or playing area. Scouter starts anywhere in the circle by whispering a message to a Cub. Cubs runs around the circle, back to his/her place and whispers to the second Cub (on his/her right) who does the same, etc. Last Cub gives the message out loud to the Pack.

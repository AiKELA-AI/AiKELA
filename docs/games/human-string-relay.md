# Human String Relay

## Type

TEAM GAME

## Equipment

A spoon and equal length of yarn per Six

## Instructions

TEAM GAME: Human String Relay Tie a spoon to the end of a ball of yarn. Line up the Sixes single-file. When the leader says “go”, the first person from each Six must put the spoon down his/her shirt, as well as his/her pants. When it comes out of his/her pants leg, he/she must then pass it to the next Cub. (As it is still attached to the first Cub). When it has gone through the entire line, and everyone is attached, then the last person at the end of the line must reverse the process (while the first Cub winds the string into a ball as it comes back out of each person’s clothing). When the Six finishes unwinding the string then the first person in that line needs to shout, “done”. The Six to finish unwinding the yarn first wins.

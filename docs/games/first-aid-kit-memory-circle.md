# First-aid Kit Memory Circle

## Type

Cumulative memory game; 10 minutes

## Equipment

Sixteen safe first-aid-kit items in the source.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

Give each Cub two items secretly. Sit in a circle with items hidden. One by one, Cubs repeat “I went on a hike and in my first-aid kit I packed…” and add one item, remembering the previous items. On the next circuit each adds their second item. The source gives no scoring threshold or elimination rule.

## Preparation and review

**Scouter guidance / extraction notes:** Use harmless demonstration items; no medicines, sharps or contaminated equipment. This game practises recall, not diagnosis or treatment and not an all-senses score.

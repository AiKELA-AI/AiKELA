# Drawing Sixes

## Type

RELAY GAME

## Equipment

Large sheet of paper and pencil for each Six

## Instructions

RELAY GAME: Drawing Sixes in separate groups, each with a large sheet of paper and a pencil. The leader, armed with a list of six objects to be drawn, stands roughly equidistant from the Sixes. On ‘go’ Sixers run up and are given the name of an object to draw, e.g. a bicycle. Each returns to his/her Six and draws in silence, the others guess aloud what it is. Artist may only answer ‘yes’ or ‘no’. When object is correctly identified, number 2 runs up for the name of another object and so on until all six objects have been drawn. First Six finished wins.

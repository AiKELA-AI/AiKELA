# Ridiculous Rounders

## Type

WIDE GAME

## Equipment

All sorts of different “bats”; ball

## Instructions

WIDE GAME: Ridiculous Rounders Cubs play the normal game of rounders BUT the fun part is that the bat is not a bat but rather anything that can hit a ball; e.g. broom, number plate, flipper, tray, spade, spatula, etc. This is really a fun game and the Cubs love it.

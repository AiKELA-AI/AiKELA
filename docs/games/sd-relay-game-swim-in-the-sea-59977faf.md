```text
Relay game – Swim in the Sea
Prior to the game, set up the following: a line for each Team
(2) onto which a plastic cup has been placed (line through the
cup). Each Six is given a pistol (empty dishwasher bottle) of
water. On ‘go’ each Cub in the Six takes it in turn to squirt
water into the cup. This will send the cup ‘swimming’ along the
line. The Six who finishes first is the winning team.
```

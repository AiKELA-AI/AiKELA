# Longest Line

## Type

REVISION GAME

## Equipment

An equal number of pieces of string (same length) per Six

## Instructions

REVISION GAME: Longest Line Each Six is given say 30 pieces of string, cut the same length. At ‘go’ each Cub joins as many pieces of string together as possible, using a reef knot. The Sixer should tie all the pieces together. The first Six to have used all their bits of string shouts ‘stop’. The lengths of string are then measured and the longest one wins. Of course, all the reef knots must be tied correctly!

```text
Revision Game -What Time is it?
Cubs line up in relay formation with a packet about 5m in front
of each Six. The PS calls out a time e.g. 8 o clock on Monday
( A time when the Pack goes to school) and the first Cub must
run to the box and take out the paper that says ‘go to school’.
Repeat until all Cubs have had a turn.
```

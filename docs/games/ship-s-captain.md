# Ship's Captain

## Type

STEAM RELEASE

## Equipment

None

## Instructions

The Captain (leader) calls orders and the Cubs, as crew, follow them. If a Cub gets an order wrong, the Captain may either eliminate them or have them lose one life. Agree which rule to use before play. Continue until one Cub remains or the allotted time ends.

Commands from the Colossus of Rhodes source:
- **Port:** run to the right side of the “boat”.
- **Starboard:** run to the left side.
- **Bow:** run to the front.
- **Stern:** run to the back.
- **Hit the deck:** lie on your stomach.
- **Attention on deck:** salute and call “Aye Aye Captain”. Stay still until the next command.
- **Sick turtle:** lie on your back with feet and hands raised.
- **Shark:** run to a designated area and shout “SHARK”; the last there is out.
- **Three men in a boat:** form groups of three and sing “row, row the boat”.

**Source variation:** The Colossus of Rhodes source says an incorrect response means out and gives the command list above. Gulliver’s Travels says a player loses a life and the game may end when time allows; it does not provide its own command list.

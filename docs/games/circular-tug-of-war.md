# Circular Tug of War

## Type

CIRCLE GAME

## Equipment

Rope, bean bag

## Instructions

CIRCLE GAME: Circular Tug of War Cubs in a circle holding onto a rope (they will work in threes). About 2 metres behind each group is a beanbag or some other object. Each group tries to pull on the rope so that one member can pick up the bean bag. Cubs need to be holding onto the rope when they pick up the beanbag.

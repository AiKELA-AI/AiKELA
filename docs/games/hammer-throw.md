# Hammer Throw

## Type

Activity

## Equipment

Paper bags, newspaper, string

## Instructions

GAME 2: Hammer throw Make a 'hammer' out of paper bags, newspaper and string. Stuff the paper bag with newspaper. Tie it off with a long string. Hold the end of the string. Spin around three times. Let go. Watch how far the hammer travels.

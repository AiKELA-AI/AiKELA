# Friendly Fiasco

## Type

RELAY GAME

## Equipment

none

## Instructions

RELAY GAME: Friendly Fiasco Cubs in relay formation. First Cub must piggy back the second Cub to the other side, a short distance ahead. The second Cub runs back and collects the third Cub and carries him/her to the demarcated area and so on until all Cubs have been carried over.

# Klompies

## Type
Active game / steam release

## Equipment

Whistle

## Instructions

The Cubs run around a designated area. The Scouter blows a whistle a number of times; Cubs form groups matching the number of blasts. Any Cubs left over sit out for one round, then rejoin.

**Source variation:** In the Ten Minutes after Midnight programme, the examples are three blasts for groups of three and two blasts for groups of two. It does not state what to do with Cubs left over. The Exploring is Fun source says left-over Cubs sit out one round.

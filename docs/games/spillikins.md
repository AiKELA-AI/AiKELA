# Spillikins

## Type

QUIET GAME

## Equipment

Medicine bottle (or similar); 6 toothpicks for each Cub

## Instructions

QUIET GAME: Spillikins The Pack sits in a circle with the medicine bottle in the centre. Each Cub takes it in turn to place the toothpick on top of the bottle, or on the toothpicks already there. If a Cub knocks any off while putting his/hers on, he/she must take back all those knocked off. The first Cub to get rid of all his/her toothpicks is the winner.

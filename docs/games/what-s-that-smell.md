# What’s that smell

## Type

CIRCLE GAME

## Equipment

Ball

## Instructions

CIRCLE GAME: What’s that smell Cubs stand in a circle. One Cub has the ball. The Cub throws the ball to another, who must name something that smells nice and then throw the ball on.

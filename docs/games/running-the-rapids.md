# Running the Rapids

## Type

CIRCLE GAME

## Equipment

None

## Instructions

CIRCLE GAME: Running the Rapids Cubs stand in a circle and are numbered off. When their number is called, the Cubs run in and out of the rapids (in and out of the Cubs in the circle) back to their original spot.

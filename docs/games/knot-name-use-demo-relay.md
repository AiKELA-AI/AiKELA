# Knot Name, Use and Demonstration Relay

## Type

Matching relay; 5 minutes

## Equipment

Knot-name cards, purpose cards and correctly tied example knots.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

Cubs line up in Sixes or pairs. Each runs to the front and makes one match: a use to a knot name, or a demonstration knot to its name. Only one match is made at a time. If a Cub does not know, explain/teach or let another Cub help.

## Preparation and review

**Scouter guidance / extraction notes:** Prepare correct name/use pairs from checked knotting material. Match-making alone does not show that a Cub can make and use all required knots.

# Safe Shore — Cub-designed Water-safety Floor Game

## Type

Game-design and led-play work session; 15 minutes designing, 20 minutes playing

## Equipment

Chalk, poster board, dice and checked water-safety scenario/challenge cards.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

Gold Cubs design a giant floor board game for younger Cubs, using safe, danger and challenge spaces. The source examples move a player forward two spaces or back three, and ask for a demonstration or a safety answer. Gold Cubs lead/referee while younger Cubs act as pieces. The source gives sample prompts but no finished board or complete question/answer set.

## Preparation and review

**Scouter guidance / extraction notes:** Run on dry land with sufficient space. Check all water-safety statements before use: the source’s example about checking rocks before jumping must not be read as permission to jump into unknown water. Designing a game is a sourced Cub task here, not permission for the assistant to invent an unsourced game. Retheming may change the fictional setting while retaining the sourced mechanic; identify the adaptation and this source.

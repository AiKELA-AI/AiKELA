# The River Is Rolling — Rescue-themed Knot Practice

## Type

Dry-land knot station; 10 minutes per rotation

## Equipment

Ropes and a stave/tree attachment point.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

The source uses a fictional river rescue to practise a round turn and two half hitches at an anchor and a bowline as a loop. It names “reach, throw, row, go (for help)” but does not provide a checked rescue lesson. Use only dry-land knot demonstration/practice; a loop in this activity must not be used to suspend, drag or rescue a child.

## Preparation and review

**Scouter guidance / extraction notes:** Keep all practice on dry land and loops off people. Obtain correct knot instruction and do not interpret the fictional setup as actual rescue training. Retheming may change the fictional setting while retaining the sourced mechanic; identify the adaptation and this source.

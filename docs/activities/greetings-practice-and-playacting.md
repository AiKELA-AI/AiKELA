# Greetings Practice and Paired Playacting

## Type

Language practice (15 minutes) then paired playacting (10 minutes)

## Equipment

Source appendix with Ndebele, Northern Sotho and Zulu phrases; checked pronunciation/language support.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

First practise the supplied greetings; then Cubs pair up and act out greeting one another using the language learnt. The source lists hello, please and thank you. It does **not** supply goodbye in this programme. Phrase accuracy and pronunciation are not verified by this extraction; obtain a competent language source before teaching.

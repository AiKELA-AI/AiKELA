# Playacting item 6

## Type

PLAYACTING

## Equipment

Black box (or something similar); whistle

## Instructions

PLAYACTING: Pass the Black Box Pass a black box (or something similar to represent a black box) around. When the whistle blows, the Cub holding the box must do something with the box for everyone else to guess what he/she is doing. E.g. he/she might use it as a pillow and pretend to go to sleep or a brick of margarine and put some on “toast”, etc.

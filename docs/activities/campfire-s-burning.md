# Campfire’s Burning

## Type

Singing

## Equipment

Not stated in this attachment.

## Instructions

Campfire’s burning,

Campfire’s burning,

Draw nearer, draw nearer,

In the gloaming, in the gloaming,

Sing and be merry,

Sind and be merry.

A different version:

Campfires burning,

Campfires burning,

Put logs on, put logs on,

Higher, higher, higher, higher,

Build up the fire,

Build up the fire.

**Programme run-sheet instructions:**

SINGING: Campfire’s Burning Cubs sit around their edible fires and sing Campfire’s Burning and, if time allows, one other favourite song.

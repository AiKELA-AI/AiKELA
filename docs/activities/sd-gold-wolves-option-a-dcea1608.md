Gold Wolves: (Option A)
♥️ 👣
Using the complex code i.e. A = ⭐; B = ; C = etc. GWs write a short message of
no more than 12 words using the number code and hand it to their buddy to solve.
Sample sentences to choose from:
1. Plastic pollution harms coral reefs, sea turtles, fsih, seabirds, and many
dolphins worldwide.
2. Healthy oceans provide food, clean air, beautiful beaches, and safe homes
for wildlife.
3. Every Cub can help ocean creatures by reducing waste and protecting
marine environments.
For noting - if this exercise is too hard, the GWs can write a shorter message by
choosing to write only the frist 5 or 6 words of the above sentences, if 12 words are
too much, however, to achieve the task for the Secret Codes badge, it will need to be
12 words.
GW: Write and decipher a complex code.

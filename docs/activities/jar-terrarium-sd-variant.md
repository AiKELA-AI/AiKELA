# Jar Terrarium — Let’s Go Wild Variant

## Type

Nature construction variant; 30 minutes

## Equipment

Clean lidded glass jar; sand/gravel, activated charcoal, draining soil, plants/moss and optional wood/stone decorations.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

The existing POP Terrarium entry uses a cut soft-drink bottle. This separately sourced **jar variant** differs in construction: clean the airtight jar; layer 2–5 cm sand/gravel, 1–2 cm charcoal and 5–10 cm soil; add decorations and small suitable plants/moss; add only enough water to moisten the setup; cap and place out of direct sun. The source advises opening the lid for a day if excessive condensation suggests overwatering. Original quantities are preserved as source guidance, not SSA requirements.

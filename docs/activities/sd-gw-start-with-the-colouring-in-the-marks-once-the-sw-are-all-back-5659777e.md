GW - start with the colouring in the marks. Once the SW are all back,
the GW will go out in small groups to find the animals outside.
So in the end everyone will have done the SW, GW and membership
advancement.
Find the animals outside:
The cubs will be given a page with the animals names. In the garden
there will be pictures of the animals with a khoki. The cubs need to
make a X next to the name using the colour by the correct animal
name.
Masks:
Each Cub chooses a Jungle Book character. Draw and decorate the
animal's face. Cut out eye holes. Attach string.
Learn to Mowgli’s brothers story while making the masks.

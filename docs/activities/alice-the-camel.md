# Alice the Camel

## Type

Singing

## Equipment

None

## Instructions

Alice the camel has 10 humps,

Alice the camel has 10 humps,

Alice the camel has 10 humps.

So go, Alice, GO!

Boom, boom, boom.

(Continue with 9, 8, 7….humps, until…)

Alice the camel has no humps,

Alice the camel has no humps,

Alice the camel has no humps.

‘Cause Alice is a HORSE!

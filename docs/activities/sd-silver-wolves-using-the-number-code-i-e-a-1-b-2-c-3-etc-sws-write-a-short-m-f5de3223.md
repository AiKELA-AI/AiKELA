```text
Silver Wolves:
Using the number code i.e. A = 1; B = 2; C= 3 etc. SWs write a short message of no
more than 12 words using the number code and hand it to their buddy to solve.
SW: Write and decipher a simple code.
Sample sentences to choose from:
1. Keep our beaches clean so dolphins, turtles, and fsih can live safely
2. Ocean animals need clean water because pollution makes their homes
dangerous and unhealthy.
3. Cubs can protect sea creatures by picking up litter during beach cleanups
regularly.
For noting - if this exercise is too hard, the SWs can write a shorter message by
choosing to write only the frist 5 or 6 words of the above sentences, if 12 words are
too much, however, to achieve the task for the Secret Codes badge, it will need to be
12 words.
Also, they are welcome to choose their own sentences if they prefer.
```

# Ceremonial Masks

## Type

ACTIVITY

## Equipment

## Instructions

ACTIVITY: Ceremonial Masks Cubs need to draw 3 ceremonial masks. They should be original designs and each to draw their own. If they don’t complete all three, to be completed at home before they can earn the badge.

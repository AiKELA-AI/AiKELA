# Clear-cup Seed Growing and Transplanting

## Type

Gardening work session with follow-up; 15-minute initial slot

## Equipment

Clear cups, seeds, soil/compost and larger pots for transplanting.

## Instructions

**Reuse status:** Reused from the supplied source; wording organised for a Scouter. Programme-specific transitions are not extracted here.

1. Mix the compost and potting soil.
2. Each Cub fills a clear cup about two-thirds full and places seeds near the side so roots can be seen.
3. Cubs care for the seedlings and report progress; the source asks for photographs.
4. Transplant once seedlings are large enough. The source gives a local return date; use the selected Pack’s calendar and evidence arrangements instead.

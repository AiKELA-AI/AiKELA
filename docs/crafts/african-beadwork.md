# African Beadwork

## Type

Handcraft

## Equipment

Paper; Magazines; Flour glue; Sosatie sticks; String or coloured cord; Method; Tear or cut paper strips into long triangle shaped pieces. Moisten the paper in a flour/water mixture and wrap around the sticks starting with the widest end first. Repeat as many times as possible and leave the beads on the sticks to dry. When dry, thread them onto string or coloured cord.

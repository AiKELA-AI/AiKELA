# Pack-specific folders

Keep Pack-approved local details and plans separate from the shared SSA knowledge in `docs/`.

Create one folder per Pack using a short, stable slug, for example `packs/2nd-sample-pack/`. Store that Pack's profile as `PACK-PROFILE.md`; keep its templates, year/term planners, meeting programmes and local visuals in subfolders there as needed. Do not use another Pack's profile or local documents as defaults.

`packs/1st-pinelands/` is the first Pack folder. Its local programme documents and planning conventions apply only to 1st Pinelands. Shared badge requirements and reusable activities remain in `docs/`.

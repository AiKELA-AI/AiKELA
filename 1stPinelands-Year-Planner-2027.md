# 1st Pinelands Year Planner — 2027

This planner groups the Challenge advancement work into focused term blocks so
Cubs can see progress and Scouters can present badges as soon as the required
evidence is complete. Each block is planned for one term; longer-running tasks
may need up to half a term of follow-up. If needed, that follow-up can overlap
the start of the next block while keeping the new block's main focus clear.
Badge presentation can happen at the usual weekly badge time when a Scouter has
verified the evidence.

The 2027 term dates follow the [Western Cape Education Department's school
calendar](https://www.westerncape.gov.za/education/school-calendar). Meeting
Fridays exclude the first and last Friday of each learner term. Challenge links
are programme targets, not automatic sign-off. Use the supplied SSA advancement
sheets to assess and record each Cub's evidence. The Interest Badge requirements
available in this project are transcribed from the August 2018 Cubs Badge Book;
check for a newer SSA source before sign-off.

The four 2027 blocks are Awareness, Community, Outdoors and Aptitude. This is a
year plan within the Pack's two-year cycle, not a claim that the full cycle is
complete. Revisit the cycle coverage when planning 2028. One Interest Badge
programme is included in each term.
